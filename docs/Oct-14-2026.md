To start off I use claude code. This clones a monorepo fullstack template and installs skills.

```bash
git clone https://github.com/leopubcode/fullstack-template.git

npx skills add mattpocock/skills
npx skills add alejandrobailo/no-use-effect
npx skills add leopubcode/ai-skills
```

You need to run this in some form of sandbox. I use docker sandbox:

```bash
brew trust docker/tap && brew install docker/tap/sbx
```

I give full permissions since it is in a sandbox, so just copy this into your `.claude/settings.json`:

```json
{
  "permissions": {
    "blockReadsOutsideWorkingDirectories": false,
    "defaultMode": "bypassPermissions",
    "dangerouslySkipPermissions": true
  }
}
```

I now run the sandbox:

```bash
sbx run claude .
```

Create an [PAT in GitHub](https://github.com/settings/personal-access-tokens) with access to a single repo and with only the following permissions:

- Metadata: Read
- Actions: Read-Write
- Issues: Read-Write
- Pull Requests: Read-Write
- Contents: Read-Write

You can then run on branch mode which is firther isolation for parallel agents

```bash
sbx run claude . --branch my-branch

# (recommended) give restricted access scope to a PAT
sbx secret set github --sandbox [SAND_BOX_NAME] # it will ask you to enter the token

# (not recommended) give full access with your default token
sbx secret set github --sandbox [SAND_BOX_NAME] -t "$(gh auth token)"

```

Setup the environemnt:

```bash
/set-up-matt-pococks-skills
/grill-with-docs
```
